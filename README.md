# Human Deepfake Detection

Project website for **From GAN-Based Models to GPT-5: A Taxonomy-Guided Study of Human Performance in Detecting Deepfake Face Images**, accepted at the 2027 IEEE Symposium on Security and Privacy.

- [Project website](https://human-deepfake-detection.github.io/)
- [Paper on arXiv](https://arxiv.org/abs/2610.23144)

## Website contents

The site presents the research overview, the Deepfake Face Artifact Taxonomy (DFAT), study findings, training videos, and citation information.

## Updating the website

Edit `index.html` and the files in `assets/`, then push to `main`. GitHub Pages publishes the repository root. The empty `.nojekyll` file keeps publication buildless.

Research datasets, analysis scripts, and practice-question PDFs are maintained separately from this website repository.
